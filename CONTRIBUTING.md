# Contribuindo

- Use commits semânticos (feat, fix, docs, refactor, style, test, chore)
- Abra branches por issue: `feat/desafio-form`, `fix/user-validation` etc.
- Abra Pull Requests descrevendo o que mudou e como testar.

## Convenções de Código

- Controllers magros; regras de negócio no `service`
- DTOs para dados de entrada; Entidades para persistência
- Validações em DTOs e Entidades
- Templates Thymeleaf com fragmentos de layout
