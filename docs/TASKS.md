# Gestão de atividades

Sugestão de Quadro (Kanban):

- Backlog: histórias de usuário e melhorias
- Em progresso: tarefa atual
- Em revisão: PR aberto
- Concluído: mergeado em main

Exemplos de tarefas:
- feat(user): criar tela e fluxo de cadastro
- feat(desafio): criar DTO e validações
- refactor(layout): extrair fragmentos base
- docs: adicionar wireframes
